# 排版组件升级设计

## 目标

在保留 WX MD Tool 现有粉色小清新视觉风格的前提下，新增轻量的“排版组件”插入能力。第一版重点服务微信公众号写作场景：用户可以从编辑器工具栏一键插入常用排版块，在 Markdown 中直接修改占位内容，在右侧预览中看到跟随主题色的效果，并复制为适合微信公众号后台粘贴的内联样式 HTML。

## 已确认决策

- 保持当前整体布局和视觉风格，不做工作台式大改版。
- 在现有编辑器工具栏新增一个 `组件` 入口。
- 普通 Markdown 能表达的组件优先使用普通 Markdown。
- 普通 Markdown 不足以表达的组件使用少量扩展块语法。
- 第一版提供 6 类组件，每类 1 个精选样式：小标题、卡片、引用框、提示框、分割线、CTA。
- 插入时直接写入可编辑的占位模板，不弹窗、不做右侧属性面板。
- 组件预览样式跟随当前主题色；开启自定义样式时跟随自定义主题色。

## 组件语法

### 普通 Markdown 模板

小标题：

```markdown
## 小标题
```

引用框：

```markdown
> 金句或引用内容
>
> -- 引用来源
```

分割线：

```markdown
---
```

### 扩展块模板

卡片：

```markdown
:::card
### 卡片标题
卡片正文内容，适合放重点、步骤或小结。
:::
```

提示框：

```markdown
:::tip
提示标题

这里填写提示内容。
:::
```

CTA：

```markdown
:::cta
行动标题

这里填写引导文字。

[按钮文案](https://example.com)
:::
```

## 用户流程

1. 用户把光标放在 Markdown 编辑器中。
2. 用户点击工具栏里的 `组件`。
3. 展开一个轻量下拉菜单，显示 6 个组件选项。
4. 用户选择某个组件。
5. 编辑器在当前光标位置插入模板，并自动补齐必要的前后空行。
6. 右侧预览立即渲染该组件，颜色跟随当前主题或自定义色。
7. 用户点击复制时，输出包含内联样式的 HTML，延续当前“粘贴到微信公众号后台”的模式。

## 架构设计

### 编辑器工具栏

在 `components/EditorToolbar.tsx` 中新增组件菜单。菜单只负责展示选项和触发插入，不负责解析或渲染。

现有 `Editor.tsx` 继续保持 textarea 编辑模型。第一版不引入富文本编辑器，也不更换编辑器核心。

### 组件模板定义

新增 `lib/layout-components.ts`，集中定义组件元数据：

- 组件 id
- 展示名称
- 简短说明
- Markdown 模板
- 是否适合包裹选中文本

这样工具栏只消费定义数据，后续新增组件时不需要把模板散落在组件代码中。

### Markdown 解析

扩展 `lib/markdown.ts` 的 `parseMarkdown` 流程，识别以下自定义块：

- `:::card ... :::`
- `:::tip ... :::`
- `:::cta ... :::`

解析策略：

- 先识别完整的扩展块。
- 块内部内容继续走 Markdown 渲染，保留标题、段落、链接、列表、加粗等能力。
- 渲染结果再包裹成带内联样式的组件 HTML。
- 不识别的扩展块按普通文本或普通 Markdown 内容降级处理。

### 主题色跟随

组件渲染使用当前文章主题来源：

- 未开启自定义样式时，使用当前主题的主色或 `theme.preview`。
- 开启自定义样式时，使用 `customStyles.primaryColor`。

样式规则：

- 卡片边框和标题强调色使用主题色。
- 提示框背景使用主题色的浅色版本。
- CTA 按钮背景使用主题色。
- 文本颜色保持可读，不强行把所有文字染成主题色。

## 兼容与安全

- 不新增外部运行时依赖，优先复用当前 `marked` 渲染链路。
- 不执行扩展块里的脚本，不为组件语法引入新的脚本执行能力。
- 扩展块内容进入 HTML 前需要复用现有 Markdown 渲染与转义策略，避免手写字符串拼接带来额外注入风险。
- 复制输出继续使用内联样式，减少微信公众号后台粘贴后丢样式的概率。

## 异常处理

- 扩展块缺少闭合 `:::` 时，不让预览崩溃；内容按普通文本或普通 Markdown 显示。
- CTA 没有链接时，显示标题和说明，不显示按钮。
- 扩展块内部 Markdown 渲染异常时，保持文章其余部分可预览。
- 未知扩展块类型降级为普通内容，不中断整篇文章渲染。

## 验证方案

实现阶段优先验证以下行为：

- 在光标位置插入 6 类组件。
- 有选中文本时，适合包裹的组件能合理使用选中文本。
- 每类组件能在右侧预览中正确渲染。
- 切换主题后组件颜色同步变化。
- 开启自定义颜色后组件颜色同步变化。
- 复制出的 HTML 包含组件内联样式。
- 缺少闭合标记的扩展块不会导致预览崩溃。

如果实现阶段引入测试框架，则补充 `parseMarkdown` 相关单元测试；如果暂不引入测试框架，则用构建、浏览器手测和复制结果检查完成验证。

## 第一版不做

- 每类组件多个样式。
- 插入组件前弹窗填写内容。
- 右侧属性面板编辑组件。
- 拖拽式排版。
- 组件预览图库。
- 整体 UI 风格重做。
- AI 写作、自动发布或平台账号接入。
